# RideWorks Brand Direction

This directory contains the approved **RideWorks final brand direction** for product implementation.

## Approved reference

- Brand direction board: `docs/branding/rideworks-brand-direction-board.webp`
- Status: approved visual direction for RideWorks.
- Repository copy: 350 × 263 WebP, derived from the approved RideWorks project board for implementation/reference.
- SHA-256 of the repository copy: `4dd937e2dc46f929e91fc201c32d138da6395d5c4c22fbbee8965e4b5376a81c`

The board establishes the RideWorks symbol/mark direction, wordmark treatment, app-icon treatment, light/dark use, and the visual themes **Data**, **Motion**, **Personal**, and **Durable**.

The repository image is a compact viewing/reference copy. For implementation, the exact color values below are authoritative; do not sample approximate values from the compressed board image.

## Color palette

| Role | Hex |
| --- | --- |
| Navy | `#0F2A44` |
| Blue | `#2563EB` |
| Green accent | `#10B981` |
| Light gray | `#E5E7EB` |

The navy and blue are the primary identity colors. Green is an accent, not a generic signal that an analytical change is beneficial. RideWorks UI must continue to distinguish directional change from supported positive/negative interpretation.

## Identity language shown on the board

- **RideWorks**
- **Built for one rider.**
- **Measure / Understand / Ride Ahead**
- **A smarter way to ride ahead.**
- **Data + Motion / Hidden K²**

These are brand-direction elements, not requirements that every phrase appear in the application shell.
